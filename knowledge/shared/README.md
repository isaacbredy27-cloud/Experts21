# Knowledge folder: shared

**Every agent** reads this folder before answering. Put documents here that several experts need:
- The current lease or LOI and its exhibits
- The candidate address(es), floor plans, and site photos
- The approved budget and funding status
- The consultant's goals, constraints, and decisions not yet in `docs/decision-log.md`

Same guidelines as the agent folders: descriptive dated file names, archive old versions, and no secrets.
