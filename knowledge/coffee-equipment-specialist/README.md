# Knowledge folder: coffee-equipment-specialist (Kenji)

`coffee-equipment-specialist` reads **every file in this folder before answering**, and treats it as its primary, most specific source. These documents override the general research in `docs/` when they conflict.

## What belongs here
Equipment quotes, spec sheets, dealer and service contracts, water test results, utility requirements.

## Guidelines
- Use Markdown, plain text, CSV, or PDF. Give files descriptive, dated names, e.g. `2026-12-03-loi-coral-way-v1.pdf`.
- Keep it current. Move superseded versions to an `archive/` subfolder, or delete them.
- Documents several agents need (a lease, the address, the budget) go in `knowledge/shared/` instead.
- Don't store passwords, bank credentials, or full ID numbers here. This folder is committed to git.
