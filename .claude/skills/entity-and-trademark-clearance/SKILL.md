# Entity and trademark clearance

## Steps
1. **Name screen:** for each candidate name, check:
   - Florida Sunbiz entity and fictitious name search (exact and similar names)
   - USPTO trademark search (classes 30 coffee, 43 café services, 35 retail) for identical or confusingly similar marks
   - Domain and Instagram/TikTok handle availability
   - Google Maps / Yelp for existing cafés with similar names in South Florida
   - Spanish and Portuguese meaning check (no unfortunate meanings)
2. **Risk rating:** clear, caution (similar marks in unrelated classes), or conflict.
3. **Entity:** recommend the structure (typically a Florida LLC; S-corp election once profitable, per CPA), registered agent, operating agreement, EIN, and fictitious name if the brand differs from the LLC name.
4. **Trademark filing:** consider a federal application in classes 30 and 43 once the name is chosen (intent-to-use is allowed).

## Output
A name screening table (name, Sunbiz, USPTO, domain, social, meaning, risk) and filing steps.

## Guardrails
- Searches are preliminary. A trademark attorney should run a clearance opinion before major brand spend.
