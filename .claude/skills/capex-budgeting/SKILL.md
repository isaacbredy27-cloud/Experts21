# Capex budgeting

## Miami baseline for 1,000–1,200 sf (docs/04, *est.*)
| Category | 2nd-gen space | Raw conversion |
|---|---|---|
| Deposits | $25–45k | $30–60k |
| Design/MEP | $10–25k | $25–50k |
| Buildout | $60–150k | $180–350k |
| Espresso program | $25–50k | same |
| Other equipment | $20–40k | same |
| FF&E/signage | $20–50k | $30–70k |
| POS/tech | $5–10k | same |
| Permits/fees | $3–15k | $10–30k |
| Professional fees | $5–15k | same |
| Opening inventory | $6–12k | same |
| Pre-opening payroll | $10–20k | same |
| Pre-launch marketing | $10–25k | same |
| Working capital (4–6 mo) | $60–120k | same |
| Contingency 10–15% | $25–55k | $50–90k |
| **Total** | **≈$265–500k** | **≈$450–800k** |

## Steps
1. Start from the baseline and adjust for the actual site (condition, sf, landlord work letter, TI).
2. Replace estimates with quotes as they arrive. Track estimate, quote, committed, and actual for each line.
3. Separate what can be **financed or leased** (equipment) from cash items.
4. Hold contingency until buildout is complete. Owners commonly underestimate by 20–50%.

## Output
A budget table with columns category, estimate, quote, source, financed?, and status, plus total cash required vs. total project cost.

## Guardrails
- Always include working capital and contingency in "total needed".
