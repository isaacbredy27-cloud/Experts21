# POS and tech evaluation

## Candidates
- **POS:** Toast, Square for Restaurants, Clover, Lightspeed.
- **Mobile ordering and loyalty:** native POS modules, or Square Loyalty, Toast Loyalty, Thanx, Paytronix.
- **Scheduling and payroll:** 7shifts, Homebase, Gusto, Toast Payroll.
- **Other:** Wi-Fi (guest network separate from POS), cameras, music (licensed service), inventory (MarketMan or the POS module).

## Steps
1. Write the requirements: counter speed, modifiers (alt-milk, shots, iced), mobile order throttling, bilingual receipts and kiosks, loyalty, gift cards, B2B invoicing, offline mode (hurricane outages), reporting and API.
2. Compare on features, hardware cost, software $/mo, processing rate (typically 2.5–3.5% + fees), contract term, integrations, support.
3. Total cost of ownership over 3 years at the forecast volume (with `financial-modeling`).
4. Recommend a stack and an implementation plan (menu build, staff training, test transactions).

## Output
A comparison table, 3-year TCO, the recommended stack, and the setup checklist.
