# Project scheduling

## Typical Miami durations (*est.*)
| Phase | Duration |
|---|---|
| Site search to LOI | 4–12 weeks |
| LOI to signed lease | 3–8 weeks |
| Design and MEP drawings | 4–8 weeks |
| Permit review (building) | 4–16+ weeks |
| Buildout | 8–16 weeks |
| Inspections, CU, DBPR opening | 2–4 weeks |
| Hiring and training | 3–4 weeks (overlaps) |
| **Signed lease to opening** | **4–9 months** |

## Steps
1. List milestones with dependencies (finish-to-start) and an owner agent for each.
2. Identify the **critical path**, usually permits then buildout then inspections.
3. Add buffers for permit resubmittals (+2–6 weeks), equipment lead times (espresso machines 2–12 weeks), and hurricane season (June–Nov).
4. **Target an opening in October or November**, before peak season and Art Basel. Avoid opening July–September.
5. Translate the schedule into lease asks (free-rent length, contingency deadlines).

## Output
A milestone table (milestone, owner, start, end, depends on, critical?) and the opening date range (best, likely, worst).
