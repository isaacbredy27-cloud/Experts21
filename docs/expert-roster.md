# Expert Roster — Miami Specialty Coffee Shop

The advisory team a consultant would assemble for opening a specialty coffee shop in Miami. Each role below becomes **one agent**. Skills are defined once and **shared** across agents (see the skills catalog and the per-agent skill list).

Built from the research in this folder ([README](README.md)). The *Docs* column points to the research files each agent should load first (01 = `01-market-overview.md`, and so on).

**Totals:** 27 agents · 39 skills · 39 skills shared by two or more agents.

## 5. How the team works together

- **A01 Engagement Lead** receives every request, sends it to the right specialists, and combines their answers using `executive-briefing`.
- **Site decision loop (the highest-risk decision, see 09-risks):** A07 shortlists sites → A03 maps competition → A10 confirms zoning and the permit path → A23 checks flood and insurance → A18 tests occupancy % and break-even → A22 negotiates the lease → A01 recommends.
- **Concept loop:** A02 + A04 define the customer → A24 sets the positioning → A05 + A06 build the menu → A18 costs it → A08 + A11 design the bar around it.
- **Launch loop:** A09 + A10 run the buildout and permits → A17 + A14 hire and train → A12 sets up the tech → A24/A25/A26 run pre-launch marketing → A27 opens B2B revenue → A13 tracks KPIs after opening.

## 6. Notes and optional additions
- **Optional roles** depending on scope: a *Roaster/Roastery Advisor* (if in-house roasting is added, +$48k–$122k plus air permits), a *Beverage Alcohol Advisor* (if beer or wine is served: 2COP license, 2% Miami-Dade F&B tax), and a *Sustainability Advisor* (packaging, waste, sourcing certifications).
- Legal and tax agents give **research support, not legal or tax advice**. A licensed Florida attorney and CPA should approve their output.
